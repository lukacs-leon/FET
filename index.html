📖 About the Project

Welcome to the Family Evaluation Tool (FET) web interface! This application is designed for transparent and gamified tracking of family members' points, tasks, and evaluations.

💡 Core Features:

  • Balances & Points: Manage family members and track their current scores.
  • Transaction Ledger: Every point addition or deduction is logged with custom reasons.
  • Advanced Search: Filter records by user ID, balance ranges, or keywords.

🚀 Upcoming Roadmap:

  • Timestamps support for ledger entries.
  • Visual statistics and charts for point tracking.
  • Family groups and registration backend support.
